JSON چیست؟ راهنمای کامل برای مبتدیان و برنامه‌نویسان

📅 ۱۹ آذر ۱۴۰۵ ⏱️ ۷ دقیقه مطالعه

اگر در حوزه برنامه‌نویسی، توسعه وب، یا حتی کار با APIهای مختلف فعالیت می‌کنید، حتماً نام JSON به گوشتان خورده است. اما JSON واقعاً چیست و چرا این‌قدر مهم شده است؟

JSON چیست؟

JSON (مخفف JavaScript Object Notation) یک فرمت سبک برای تبادل داده است که برای خوانایی انسان و پردازش ماشین طراحی شده. در واقع، JSON یک زبان برنامه‌نویسی نیست، بلکه روشی برای ذخیره و انتقال اطلاعات است.

JSON توسط Douglas Crockford در اوایل دهه ۲۰۰۰ معرفی شد و اکنون استاندارد جهانی تبادل داده در وب است. اکثر APIهای مدرن (توییتر، گوگل، تلگرام، و...) داده‌ها را در قالب JSON برمی‌گردانند.

ساختار JSON چگونه است؟

JSON از دو ساختار اصلی تشکیل شده:

۱. آبجکت (Object)

مجموعه‌ای از جفت‌های «کلید: مقدار» که بین آکولاد `` قرار می‌گیرند. 

{
  "name": "Ali",
  "age": 30,
  "city": "Tehran"
}

۲. آرایه (Array)

لیستی از مقادیر که بین کروشه `[]` قرار می‌گیرند. 

["Ali", "Sara", "Reza"]

قوانین مهم JSON

  • همه کلیدها باید در کوتیشن دوگانه باشند
  • مقادیر رشته‌ای نیز در کوتیشن دوگانه هستند
  • اعداد بدون کوتیشن هستند
  • کاما بعد از آخرین آیتم مجاز نیست
  • کامنت‌گذاری مجاز نیست
  • استفاده از تک‌کوتیشن مجاز نیست

چرا JSON محبوب است؟

  1. خوانایی بالا: انسان می‌تواند JSON را راحت‌تر از XML بخواند
  2. پردازش سریع: مرورگرها JSON را بسیار سریع‌تر از XML پارس می‌کنند
  3. پشتیبانی جهانی: همه زبان‌های برنامه‌نویسی از JSON پشتیبانی می‌کنند
  4. حجم کم: JSON حجم کمتری از XML دارد

مقایسه JSON و XML

در JSON: 

{"name": "Ali", "age": 30}

همان داده در XML: 

<person>
  <name>Ali</name>
  <age>30</age>
</person>

همان‌طور که می‌بینید، JSON بسیار مختصرتر است.

کاربردهای JSON

  • APIها: اکثر APIهای وب از JSON استفاده می‌کنند
  • فایل‌های تنظیمات: package.json در Node.js
  • ذخیره‌سازی موقت: localStorage مرورگر
  • تبادل داده بین سیستم‌ها: استاندارد صنعتی
  • پایگاه داده NoSQL: MongoDB از فرمت BSON (مشابه JSON) استفاده می‌کند

ابزارهای JSON در سایت ما

اگر با JSON کار می‌کنید، این ابزارها می‌توانند به شما کمک کنند:

  • فرمت‌کننده JSON - مرتب‌سازی، فشرده‌سازی و اعتبارسنجی
  • رمزگذار Base64 - برای انتقال امن JSON حاوی کاراکترهای خاص
  • مبدل CSV به JSON - برای کار با داده‌های جدولی

اشتباهات رایج در کار با JSON

  1. استفاده از تک‌کوتیشن: {'name': 'Ali'} نامعتبر است
  2. کامای اضافه: {"a": 1,} نامعتبر است
  3. کامنت‌گذاری: {"a": 1 /* comment */} نامعتبر است
  4. عدم escape کردن کاراکترهای خاص: باید از `\n`, `\t`, `\"` استفاده کنید

جمع‌بندی

JSON یک فرمت سبک و خوانا برای تبادل داده است که امروزه استاندارد جهانی شده. اگر با APIها، برنامه‌نویسی وب، یا هر سیستمی که داده مبادله می‌کند کار می‌کنید، یادگیری JSON ضروری است. برای کار با JSON، از ابزار فرمت‌کننده JSON ما استفاده کنید که کاملاً محلی اجرا می‌شود.

سوالات متداول

JSON یک زبان برنامه‌نویسی است؟

خیر. JSON مخفف JavaScript Object Notation است و یک فرمت تبادل داده است، نه یک زبان برنامه‌نویسی. اما سینتکس آن شبیه جاوااسکریپت است.

تفاوت JSON و XML چیست؟

JSON سبک‌تر، خواناتر برای انسان، و برای مرورگرها سریع‌تر پردازش می‌شود. XML برای اسناد پیچیده و سلسله‌مراتبی بهتر است. امروزه اکثر APIهای مدرن از JSON استفاده می‌کنند.

آیا JSON امن است؟

خود JSON فقط یک فرمت متن است و امن یا ناامن بودن آن به نحوه پردازش شما بستگی دارد. هرگز JSON نامعتبر را مستقیماً اجرا نکنید و همیشه اعتبارسنجی کنید.

چگونه JSON را اعتبارسنجی کنیم؟

با استفاده از ابزار آنلاین اعتبارسنجی JSON، یا با JSON.parse در جاوااسکریپت. ابزار ما هم پیام خطای دقیق و هم شماره خط و ستون را نشان می‌دهد.
