آموزش Regex: راهنمای کامل عبارات منظم (Regular Expressions)

📅 ۲۱ آذر ۱۴۰۵ ⏱️ ۸ دقیقه مطالعه

Regex (Regular Expression) یا «عبارت منظم»، یکی از قدرتمندترین ابزارهای برنامه‌نویسی برای کار با متن است. اگرچه سینتکس آن در ابتدا ترسناک به نظر می‌رسد، اما یادگیری آن باعث می‌شود که بتوانید کارهایی انجام دهید که در غیر این صورت ساعت‌ها طول می‌کشید.

Regex چیست؟

Regex یک زبان برای توصیف الگوهای متنی است. با آن می‌توانید بررسی کنید آیا یک رشته شامل الگوی خاصی است یا خیر، بخش‌هایی از آن را استخراج کنید یا جایگزین نمایید.

کاراکترهای مهم در Regex

  • .: هر کاراکتری به جز خط جدید
  • \d: هر رقم (0-9)
  • \w: هر حرف، رقم یا زیرخط
  • \s: هر فاصله، Tab یا خط جدید
  • ^: ابتدای رشته
  • $: انتهای رشته

تکرارها (Quantifiers)

  • *: صفر یا بیشتر (مثلاً a* یعنی صفر یا چند تا a)
  • +: یک یا بیشتر
  • ?: صفر یا یک (اختیاری)
  • {n}: دقیقاً n بار
  • {n,m}: بین n تا m بار

مثال‌های کاربردی

اعتبارسنجی ایمیل: ^[\w.-]+@[\w.-]+\.[a-zA-Z]{2,}$

اعتبارسنجی شماره موبایل ایران: ^09\d{9}$

استخراج لینک‌ها: https?://[^\s]+

ابزار تست Regex

برای تست و دیباگ Regexها، می‌توانید از ابزار تست Regex ما استفاده کنید. این ابزار با استفاده از Web Worker اجرا می‌شود تا از قفل شدن صفحه در برابر الگوهای خطرناک (ReDoS) جلوگیری کند.

نکات مهم برای استفاده امن

  • از الگوهای بسیار پیچیده پرهیز کنید.
  • برای ورودی‌های کاربر، محدودیت طول بگذارید.
  • در سرور، از timeout برای پردازش Regex استفاده کنید.

جمع‌بندی

Regex یک مهارت ضروری برای هر برنامه‌نویس است. با یادگیری اصول اولیه و استفاده از ابزارهای تست، می‌توانید بسیاری از کارهای پیچیده متنی را در چند ثانیه انجام دهید.

Regular expressions (regex) are among the most powerful tools for working with text in software development. Their syntax can look intimidating at first, but a few core concepts make many text-processing tasks much easier.

What is a regular expression?

A regular expression describes a text pattern. You can use it to check whether a string matches a rule, find and extract parts of a string, or replace matching content.

Useful regex characters

  • . — matches any character except a line terminator in the usual default mode.
  • \\d — matches a digit (0–9 in common JavaScript regex usage).
  • \\w — matches a word character, typically a Latin letter, digit, or underscore in JavaScript.
  • \\s — matches whitespace, including spaces, tabs, and line breaks.
  • ^ — matches the beginning of the input (or line in multiline mode).
  • $ — matches the end of the input (or line in multiline mode).

Quantifiers

  • * — zero or more repetitions; for example, a* matches zero or more consecutive a characters.
  • + — one or more repetitions.
  • ? — zero or one repetition (optional).
  • {n} — exactly n repetitions.
  • {n,m} — between n and m repetitions.

Practical examples

A simple email-shaped pattern:
^[\\w.-]+@[\\w.-]+\\.[a-zA-Z]{2,}$

This is only a basic format check, not a complete implementation of email-address validation.

Iranian mobile number format:
^09\\d{9}$

Finding URL-like strings:
https?://[^\\s]+

These examples are starting points. Real validation rules should reflect the actual requirements and accepted formats of your application.

Test regex patterns online

Use our Regex Tester to test and debug patterns against sample text. The tool uses a Web Worker to keep pattern evaluation away from the main page thread. This improves responsiveness, but it does not make every potentially expensive regular expression harmless.

Safer regular-expression practices

  • Avoid unnecessarily complex patterns and ambiguous nested quantifiers.
  • Set reasonable length limits on user-supplied input.
  • When regex runs on a server, use execution limits or other safeguards appropriate to the runtime.
  • Test patterns with both expected input and adversarial edge cases.
  • Prefer a parser or dedicated validation library when the format is too complex for a maintainable regex.

Summary

Regular expressions are a valuable skill for developers who search, validate, extract, or transform text. Learn the basic tokens and quantifiers, test patterns carefully, and keep performance and input limits in mind. Try the online Regex Tester to experiment with your own expressions.

Frequently Asked Questions

What is a regular expression (regex)?

A regular expression is a pattern language for searching, validating, extracting, and replacing parts of text.

Is regex syntax identical in every programming language?

The fundamentals are similar, but engines and language APIs differ. JavaScript, Python, and PHP, for example, do not support exactly the same features. Check the documentation for your target environment.

Why can regex be difficult for beginners?

Compact symbols can make patterns hard to read. Start with small expressions, test them against representative input, and add complexity gradually.

What is ReDoS?

Regular Expression Denial of Service (ReDoS) occurs when a vulnerable pattern causes excessive backtracking and consumes substantial processing time. Limit input size and avoid ambiguous, nested repetition.
