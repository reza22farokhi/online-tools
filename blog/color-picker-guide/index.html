آموزش استخراج کد رنگ از تصویر (Color Picker)

📅 ۲۵ آذر ۱۴۰۵ ⏱️ ۵ دقیقه مطالعه

پس از استخراج رنگ، برای ساخت یک پالت هماهنگ به راهنمای تولید پالت رنگ مراجعه کنید.

انتخاب رنگ از تصویر یک مهارت ضروری برای طراحان گرافیک، توسعه‌دهندگان وب و هر کسی است که با تصاویر کار می‌کند. تصور کنید یک عکس زیبا از یک غروب پیدا کرده‌اید و می‌خواهید از رنگ نارنجی آن در طراحی سایت خود استفاده کنید — چطور آن رنگ را دقیقاً پیدا می‌کنید؟

در این راهنما، یاد می‌گیرید چطور با ابزارهای ساده، رنگ دقیق هر نقطه از یک تصویر را استخراج کنید.

کاربردهای انتخاب رنگ از تصویر

  • طراحی وب: استخراج رنگ از لوگو یا عکس برای هماهنگی با سایت
  • طراحی گرافیک: پیدا کردن رنگ دقیق برای پوستر یا بنر
  • عکاسی: بررسی رنگ‌های اصلی یک عکس
  • دکوراسیون: استخراج پالت رنگی از عکس یک اتاق برای خرید مبلمان
  • مد: پیدا کردن رنگ دقیق یک لباس برای خرید آنلاین

فرمت‌های نمایش رنگ

HEX (هگزادسیمال)

فرمت رایج در CSS. یک علامت # و ۶ کاراکتر (۰-۹ و A-F). مثال: #FF5733 (نارنجی).

RGB (سرخ، سبز، آبی)

سه عدد بین ۰ تا ۲۵۵. مثال: rgb(255, 87, 51). خوانایی بیشتری برای انسان دارد.

HSL (رنگ، اشباع، روشنایی)

نمایش شهودی‌تر: H (۰-۳۶۰ درجه)، S (۰-۱۰۰٪)، L (۰-۱۰۰٪). مثال: hsl(9, 100%, 60%).

ابزار انتخاب رنگ از تصویر

با ابزار انتخاب رنگ از تصویر ما می‌توانید:

  1. یک تصویر آپلود کنید (حداکثر ۲۰ مگابایت)
  2. روی هر نقطه از تصویر کلیک کنید
  3. کد HEX و RGB آن نقطه را ببینید
  4. با یک کلیک، کد را کپی کنید

این ابزار کاملاً محلی اجرا می‌شود و تصویر شما هرگز به سرور ارسال نمی‌شود.

نکات مهم در انتخاب رنگ

۱. کنتراست کافی

هرگز رنگ متن را با رنگ پس‌زمینه‌ای که کنتراست کافی ندارد (کمتر از ۴.۵:۱) استفاده نکنید. این روی خوانایی و سئو اثر منفی می‌گذارد. با ابزار بررسی کنتراست ما می‌توانید بررسی کنید.

۲. هارمونی رنگ

رنگ‌های انتخابی باید با هم هماهنگ باشند. سه نوع اصلی هارمونی:

  • آنالوگ: رنگ‌های نزدیک به هم (مثل آبی، فیروزه‌ای، سبز) — آرامش‌بخش
  • مکمل: رنگ‌های متضاد (مثل آبی و نارنجی) — جذاب
  • سه‌گانه: سه رنگ با فاصله ۱۲۰ درجه — پرانرژی

۳. روان‌شناسی رنگ

  • قرمز: هیجان، فوریت (مناسب دکمه "خرید")
  • آبی: اعتماد، آرامش (مناسب سایت‌های مالی)
  • سبز: رشد، موفقیت (مناسب دکمه "تایید")
  • زرد: هشدار (مناسب پیام‌های توجه)
  • خاکستری: حرفه‌ای، خنثی (مناسب متن)

محدودیت‌های رنگ روی نمایشگر

رنگ استخراج‌شده از تصویر، دقیقاً همان رنگی است که در فایل وجود دارد. اما توجه کنید:

  • هر نمایشگر، رنگ را کمی متفاوت نشان می‌دهد (به‌خصوص اگر کالیبره نباشد)
  • در چاپ، رنگ‌ها با نمایشگر متفاوت خواهند بود (CMYK در برابر RGB)
  • محیط نور اطراف روی درک رنگ اثر می‌گذارد

جمع‌بندی

انتخاب رنگ از تصویر یک مهارت ضروری برای طراحان است. با ابزار color picker آنلاین ما، می‌توانید در چند ثانیه رنگ دقیق هر نقطه را استخراج کنید. برای طراحی حرفه‌ای، همیشه کنتراست و هارمونی را در نظر بگیرید.

Sampling a color from an image is useful when you want a design to match a photograph, logo, illustration, or visual reference. A color picker reads a pixel value and presents it in a format that can be reused in CSS or a graphics application.

Common uses

  • Web design: match a website accent to a brand image or photograph.
  • Graphic design: reuse a color from an existing poster or illustration.
  • Photography: inspect dominant or specific colors in an image.
  • Product design: build a coordinated palette from a visual reference.

Understand color formats

HEX

HEX notation represents red, green, and blue channel values using hexadecimal digits. For example, #FF5733 is a vivid orange-red.

RGB

RGB expresses the red, green, and blue channels as decimal values, commonly from 0 to 255. The same example is rgb(255, 87, 51).

HSL

HSL describes a color using hue, saturation, and lightness. It can be convenient when you want to adjust brightness or saturation while keeping a similar hue.

Pick a color from an image

Open our Color Picker, select an image, and click the point you want to sample. The tool displays the pixel color in supported formats so you can copy the value into your project. The image is processed in your browser.

Check contrast before using the color

A sampled color may look good in an image but still be difficult to read as text on a particular background. Test the foreground and background with our Contrast Checker. For a coordinated set of colors, continue with our color palette guide.

Understand display differences

The sampled value comes from the image's pixel data, but two screens may display it differently because of display calibration, color profiles, brightness, and ambient lighting. Printed colors can differ further because print workflows use different color models and output characteristics.

Summary

A color picker helps extract reusable values from images. Use HEX, RGB, or HSL according to your workflow, and always check contrast and display context before using the color in a user interface.

سوالات متداول

انتخاب رنگ از تصویر چه کاربردی دارد؟

این کار برای طراحان گرافیک، توسعه‌دهندگان وب، و هر کسی که می‌خواهد رنگ دقیق یک تصویر را استخراج کند ضروری است. مثلاً می‌خواهید رنگ پس‌زمینه یک عکس را در سایت خود استفاده کنید.

فرمت‌های رنگ HEX و RGB چه تفاوتی دارند؟

HEX یک نمایش ۶ رقمی هگزادسیمال است (مثل #FF0000 برای قرمز). RGB سه عدد بین ۰ تا ۲۵۵ است (مثل rgb(255, 0, 0)). هر دو یک رنگ را نمایش می‌دهند، اما HEX در CSS رایج‌تر است و RGB خوانایی بیشتری برای انسان دارد.

چگونه رنگ مناسب برای طراحی انتخاب کنیم؟

عوامل مهم: کنتراست کافی (برای خوانایی)، هارمونی رنگ (برای زیبایی)، و روان‌شناسی رنگ (قرمز برای هیجان، آبی برای اعتماد). ابزارهای ما می‌توانند به شما در انتخاب کمک کنند.

آیا رنگ استخراج‌شده دقیق است؟

بله، ابزار ما رنگ دقیق هر پیکسل را استخراج می‌کند. دقت تا ۱ پیکسل. اما توجه کنید که رنگ روی صفحه نمایش ممکن است با چاپ یا محیط‌های دیگر کمی متفاوت دیده شود.

Frequently Asked Questions

Why sample a color from an image?

Sampling helps designers and developers reuse a color from a photograph, logo, illustration, or reference image in a design project.

What is the difference between HEX and RGB?

HEX represents red, green, and blue channel values using hexadecimal notation. RGB represents the same channels as decimal values, usually from 0 to 255.

Is the sampled color always identical on every screen?

The sampled value represents the pixel data in the image, but displays, color profiles, brightness, and ambient lighting can make the visible result differ.

Can I use a sampled color as an accessible text color?

Not without checking contrast. Test the sampled foreground against its intended background and verify the relevant WCAG contrast requirement.
