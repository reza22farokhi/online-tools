راهنمای کامل تبدیل CSV به JSON و برعکس

📅 ۲۶ آذر ۱۴۰۵ ⏱️ ۶ دقیقه مطالعه

در دنیای داده‌ها، دو فرمت بیشتر از بقیه استفاده می‌شوند: CSV (برای انسان‌ها) و JSON (برای ماشین‌ها). بسیاری از پروژه‌ها نیاز دارند داده‌ها را بین این دو فرمت تبدیل کنند. اما این تبدیل، پیچیدگی‌های خاص خودش را دارد.

CSV چیست؟

CSV (Comma-Separated Values) یک فرمت متنی ساده است که داده‌ها را با کاما از هم جدا می‌کند. هر خط، یک ردیف داده است و هر کاما، یک ستون. 

name,age,city
Ali,30,Tehran
Sara,25,Shiraz
Reza,28,Mashhad

CSV برای Excel، Google Sheets و ابزارهای داده مناسب است، اما ساختار سلسله‌مراتبی ندارد.

JSON چیست؟

JSON (JavaScript Object Notation) یک فرمت ساختاریافته است که داده‌ها را به صورت شیء یا آرایه نمایش می‌دهد. 

[
  {"name": "Ali", "age": 30, "city": "Tehran"},
  {"name": "Sara", "age": 25, "city": "Shiraz"},
  {"name": "Reza", "age": 28, "city": "Mashhad"}
]

JSON برای APIها، برنامه‌نویسی و ساختارهای پیچیده مناسب است.

تبدیل CSV به JSON

برای تبدیل CSV به JSON، مراحل ساده است:

  1. خط اول = نام ستون‌ها (header)
  2. هر خط بعدی = یک ردیف داده
  3. هر ردیف به یک شیء JSON تبدیل می‌شود

با ابزار مبدل CSV به JSON ما، این کار در یک کلیک انجام می‌شود.

تبدیل JSON به CSV

برای تبدیل JSON به CSV:

  1. تمام کلیدهای آبجکت‌ها را استخراج کنید (این‌ها ستون‌ها می‌شوند)
  2. هر آبجکت = یک ردیف
  3. مقادیر را با کاما از هم جدا کنید

چالش‌های تبدیل

۱. کوتیشن‌ها

اگر یک مقدار شامل کاما باشد (مثل «Tehran, Iran»)، باید در کوتیشن قرار گیرد: 

name,city
Ali,"Tehran, Iran"

ابزار ما به‌طور خودکار این کوتیشن‌ها را مدیریت می‌کند.

۲. ستون‌های ناقص

اگر یک ردیف ستون کمتری داشته باشد، باید با مقدار خالی پر شود. ابزار ما این را پشتیبانی می‌کند.

۳. جداکننده‌های مختلف

بعضی از فایل‌ها به جای کاما از سمی‌کالن (;) یا Tab استفاده می‌کنند. ابزار ما هر سه را پشتیبانی می‌کند.

کاربردهای تبدیل

  • مهاجرت داده: انتقال داده از Excel به دیتابیس
  • API: تبدیل داده‌های CSV به JSON برای ارسال به API
  • تحلیل داده: پردازش داده‌های Excel در Python یا JavaScript
  • پشتیبان‌گیری: ذخیره داده‌ها در فرمت خوانا

ابزار مبدل CSV/JSON

با ابزار مبدل CSV به JSON ما:

  • می‌توانید فایل CSV خود را جای‌گذاری کنید
  • جهت تبدیل (CSV به JSON یا برعکس) را انتخاب کنید
  • جداکننده را مشخص کنید (کاما، سمی‌کالن، Tab)
  • نتیجه را در چند ثانیه ببینید

این ابزار کاملاً محلی اجرا می‌شود و داده‌های شما هرگز به سرور ارسال نمی‌شود.

جمع‌بندی

تبدیل CSV به JSON یک کار ضروری در پروژه‌های داده است. با ابزار آنلاین ما، این کار در چند ثانیه و بدون ارسال داده به سرور انجام می‌شود. برای برنامه‌نویسان و تحلیل‌گران داده، این ابزار یک ضرورت است.

CSV and JSON are two common formats for storing and exchanging data. CSV is convenient for spreadsheets and flat tables, while JSON is widely used by web APIs and applications. Converting between them is straightforward for simple records, but details such as quoting, missing values, and nested objects deserve attention.

What is CSV?

CSV means Comma-Separated Values. It is a text format in which each line usually represents a row and delimiters separate the fields. The first row often contains column names.

name,age,city
Ali,30,Tehran
Sara,25,Shiraz
Reza,28,Mashhad

CSV is easy to export from spreadsheet applications, but it does not define a universal way to represent nested objects, arrays, or data types.

What is JSON?

JSON (JavaScript Object Notation) represents data using objects, arrays, strings, numbers, booleans, and null values. A table can be represented as an array of objects, with each row becoming one object.

[
  {"name":"Ali","age":30,"city":"Tehran"},
  {"name":"Sara","age":25,"city":"Shiraz"},
  {"name":"Reza","age":28,"city":"Mashhad"}
]

JSON is useful for APIs and application data because it can represent nested structures as well as flat records.

Convert CSV to JSON

  1. Identify the header row and use its values as object keys.
  2. Read each subsequent row as a record.
  3. Map each field to its corresponding header.
  4. Check how empty cells and values that look like numbers or dates should be represented.

Convert JSON to CSV

For a simple array of objects, collect the keys that should become columns, write them as the header row, and write each object's values in the same column order. Decide how to handle missing keys, null values, and nested objects before exporting. A nested value may need to be flattened or serialized into a single field.

Quoting and delimiters

A field containing a comma, quotation mark, or line break must be handled according to CSV quoting rules. For example:

name,city
Ali,"Tehran, Iran"

Inside a quoted CSV field, a literal double quote is commonly escaped by doubling it. Not every file uses a comma: semicolons and tab characters are also common delimiters. Select the delimiter that matches the source file rather than assuming all CSV files are identical.

Missing values and data types

CSV fields are text by default. A value such as 00123 might be an identifier, not the number 123; converting it to a number would remove leading zeroes. Dates and decimal separators can also be ambiguous. Decide on a schema and validate the converted output against it.

Common uses

  • Data migration: Move a spreadsheet export into an application or database.
  • API integration: Convert tabular records into JSON request data.
  • Analysis: Load spreadsheet data into JavaScript, Python, or another analysis environment.
  • Exchange: Share flat records in a format supported by the receiving system.

Summary

CSV is a practical format for flat tables, while JSON is better suited to structured application data. Before converting, check headers, quoting, delimiters, missing values, and data types. Always inspect the result and validate it against the requirements of the system that will consume it.

سوالات متداول

CSV و JSON چه تفاوتی دارند؟

CSV یک فرمت متنی ساده است که داده‌ها را با کاما از هم جدا می‌کند (مناسب Excel). JSON یک فرمت ساختاریافته است که داده‌ها را به صورت شیء نمایش می‌دهد (مناسب APIها و برنامه‌نویسی). هر دو برای ذخیره داده استفاده می‌شوند اما کاربردهای متفاوتی دارند.

چرا از CSV به JSON تبدیل کنیم؟

APIهای مدرن معمولاً JSON می‌پذیرند نه CSV. اگر داده‌ها را از Excel یا Google Sheets خارج کرده‌اید (CSV)، برای استفاده در برنامه یا ارسال به API، باید به JSON تبدیل شوند.

آیا هنگام تبدیل، داده‌ها از بین می‌روند؟

در تبدیل ساده، ممکن است ساختار (مثل ادغام سلول‌ها در Excel) از بین برود، اما داده‌ها حفظ می‌شوند. برای حفظ ساختار پیچیده، باید تبدیل‌های پیچیده‌تری انجام دهید.

آیا تبدیل CSV به JSON امن است؟

اگر ابزار آنلاین، داده‌ها را به سرور ارسال نکند، بله. ابزار ما کاملاً محلی اجرا می‌شود و داده‌های شما هرگز از مرورگر خارج نمی‌شود.

Frequently Asked Questions

What is the difference between CSV and JSON?

CSV represents tabular data as rows and delimited fields. JSON represents structured values such as objects and arrays, so it can model nested data more naturally.

Why convert a CSV file to JSON?

Many web APIs and JavaScript applications exchange structured data as JSON. Converting a spreadsheet export to JSON can make its rows easier to consume in those systems.

Can conversion change or lose data?

It can. CSV has no built-in types or nested structure, so a converter must make choices about headers, empty cells, numbers, quoting, and nested values. Review the output before using it.

Is this converter suitable for private data?

The converter on this site is designed to process input locally in your browser. Avoid entering sensitive data into unfamiliar websites, and verify network behaviour if your workflow has strict confidentiality requirements.
