Frequently asked questions about Color Picker from Image

How precise is the color picker?

The picker samples the selected image pixel. Click the point you want to inspect to retrieve its color value.

Which color formats are available?

The tool displays the selected color in HEX (for example, #FF0000) and RGB (for example, rgb(255, 0, 0)) formats, which you can copy.

What is the maximum image size?

The maximum supported input file size is 20 MB. If your image is larger, resize or compress it before uploading it to the picker.
