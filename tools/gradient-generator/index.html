تولیدکننده گرادیانت CSS

گرادیانت خطی و شعاعی CSS با چند رنگ بسازید، زاویه و توقف رنگ‌ها را تنظیم کنید و پیش‌نمایش زنده همراه با کد آماده دریافت کنید.

 
 
 
 
 
 
حریم خصوصی
 
محتوایی که در این ابزار وارد یا انتخاب می‌کنید، در مرورگر شما پردازش می‌شود و برای انجام پردازش به سرورهای ما ارسال نمی‌شود. برای جزئیات بیشتر، سیاست حریم خصوصی را بخوانید.
 
 
 
سوالات متداول درباره تولیدکننده گرادیانت CSS
 
 
 چه نوع گرادیانت‌هایی پشتیبانی می‌شوند؟ 
خطی با زاویه دلخواه و شعاعی. تا ۵ رنگ در هر گرادیانت.
 
 آیا می‌توانم کد CSS را مستقیماً استفاده کنم؟ 
بله. دکمه کپی کد CSS معادل دقیق را در کلیپ‌بورد کپی می‌کند.
 
 ترتیب رنگ‌ها چطور تعیین می‌شود؟ 
بر اساس موقعیت (position) هر رنگ. ابزار به‌طور خودکار رنگ‌ها را بر اساس موقعیت مرتب می‌کند.
