تبدیل فایل به Base64

فایل خود (مانند تصویر، PDF یا فونت) را به متن Base64 تبدیل کنید تا در کدهای HTML یا CSS استفاده کنید.

فایل: -

حریم خصوصی

این ابزار کاملاً در مرورگر شما اجرا می‌شود و هیچ داده‌ای به سرور ارسال نمی‌شود. تمام پردازش‌ها به‌صورت محلی روی دستگاه شما انجام می‌شوند.

سوالات متداول درباره تبدیل فایل به Base64

Base64 Data URI چیست؟

یک فرمت برای جاسازی فایل در HTML یا CSS به صورت متن. مثال: data:image/png;base64,iVBOR...

حداکثر حجم فایل چقدر است؟

حداکثر ۱۰ مگابایت. برای فایل‌های بزرگ‌تر، مرورگر ممکن است کند شود.

آیا می‌توانم از این برای تصاویر سایت استفاده کنم؟

برای تصاویر کوچک (آیکون، لوگو) بله. برای تصاویر بزرگ توصیه نمی‌شود چون حجم HTML را زیاد می‌کند.

رمزگذاری و رمزگشایی Base64

متن را به Base64 تبدیل کنید یا Base64 را رمزگشایی کنید. با پشتیبانی UTF-8، حالت URL-safe و پردازش محلی.

مشاهده اطلاعات فایل و هش

اطلاعات دقیق فایل (حجم، نوع، پسوند) را ببینید و هش SHA-256 آن را برای بررسی اصالت محاسبه کنید.
