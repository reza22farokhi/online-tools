حریم خصوصی

این ابزار کاملاً در مرورگر شما اجرا می‌شود و هیچ داده‌ای به سرور ارسال نمی‌شود. تمام پردازش‌ها به‌صورت محلی روی دستگاه شما انجام می‌شوند.

سوالات متداول درباره مشاهده اطلاعات فایل و هش

حداکثر حجم فایل چقدر است؟

حداکثر ۵۰ مگابایت. برای فایل‌های بزرگ‌تر، محاسبه هش ممکن است حافظه مرورگر را پر کند.

هش SHA-256 چه کاربردی دارد؟

برای بررسی اصالت فایل. اگر هش محاسبه‌شده با هش رسمی مطابقت داشته باشد، فایل دستکاری نشده است.

آیا فایل به سرور ارسال می‌شود؟

خیر. تمام محاسبات با FileReader و Web Crypto API در مرورگر شما انجام می‌شود.

تبدیل فایل به Base64

فایل خود (مانند تصویر، PDF یا فونت) را به متن Base64 تبدیل کنید تا در کدهای HTML یا CSS استفاده کنید.
