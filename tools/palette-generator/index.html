تولیدکننده پالت رنگ

از رنگ پایه پالت هماهنگ بسازید؛ ترکیب‌های مکمل، مشابه، سه‌گانه و تک‌رنگ را ببینید و کدهای HEX را برای طراحی و ساخت تم‌های هماهنگ کپی کنید.

حریم خصوصی

محتوایی که در این ابزار وارد یا انتخاب می‌کنید، در مرورگر شما پردازش می‌شود و برای انجام پردازش به سرورهای ما ارسال نمی‌شود. برای جزئیات بیشتر، سیاست حریم خصوصی را بخوانید.

سوالات متداول درباره تولیدکننده پالت رنگ

هارمونی رنگی چیست؟

ترکیب منظم رنگ‌ها بر اساس موقعیت آن‌ها در دایره رنگ. انواع: مکمل، آنالوگ، سه‌گانه، چهارگانه، تک‌رنگ و Split.

کدام هارمونی برای طراحی مناسب است؟

برای محتوا: آنالوگ (آرامش) یا Split (تعادل). برای برند: مکمل (تضاد قوی). انتخاب به حس موردنظر بستگی دارد.

آیا می‌توانم پالت را ذخیره کنم؟

با کلیک روی هر رنگ آن را کپی می‌کنید. با دکمه کپی همه، همه رنگ‌ها با هم کپی می‌شوند.

Frequently asked questions about Color Palette Generator

What does Color Palette Generator do?

Generate harmonious color palettes from a base color, explore complementary, analogous, triadic, and monochromatic schemes, and copy HEX values.

How do I use Color Palette Generator?

Enter or select the required input, adjust any available options, and review the result. Use the copy or download control when it is available.
