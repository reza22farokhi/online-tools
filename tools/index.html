📝 متن

📝

شمارش کلمات و کاراکترها

تعداد کلمات، کاراکترها، جمله‌ها، خطوط و پاراگراف‌های متن را به‌صورت لحظه‌ای بشمارید.

متن
📝

تبدیل حروف کوچک و بزرگ

متن را به حروف بزرگ، کوچک، عنوان، جمله، camelCase، PascalCase، snake_case یا kebab-case تبدیل کنید.

متن
📝

حذف فاصله‌های اضافی

فاصله‌های تکراری، فاصله ابتدا/انتهای خطوط و خطوط خالی را با یک کلیک حذف کنید.

متن
📝

مرتب‌سازی خطوط

خطوط متن را به‌صورت الفبایی، عددی، بر اساس طول یا برعکس مرتب کنید. با گزینه‌های حذف خطوط تکراری و خالی.

متن
📝

حذف خطوط تکراری

خطوط تکراری متن را با حفظ ترتیب اصلی حذف کنید. با گزینه‌های حساسیت به حروف بزرگ/کوچک و حذف خطوط خالی.

متن
📝

تبدیل متن به Slug

متن فارسی یا انگلیسی را به Slug خوانا و سئوپسند تبدیل کنید. نرمال‌سازی فارسی، حذف کاراکترهای غیرمجاز، طول قابل تنظیم.

متن

💻 برنامه‌نویسی

💻

فرمت‌بندی، کوچک‌سازی و اعتبارسنجی JSON

JSON را مرتب (Pretty-Print)، کوچک (Minify) یا اعتبارسنجی کنید. با پیام خطای دقیق و پردازش کاملاً محلی.

برنامه‌نویسی
💻

رمزگذاری و رمزگشایی Base64

متن را به Base64 تبدیل کنید یا Base64 را رمزگشایی کنید. با پشتیبانی UTF-8، حالت URL-safe و پردازش محلی.

برنامه‌نویسی
💻

تبدیل و بازگردانی HTML Escape

کاراکترهای خاص HTML را به entity تبدیل کنید یا entityها را به کاراکتر اصلی بازگردانید. امن و آفلاین.

برنامه‌نویسی
💻

رمزگذاری و رمزگشایی URL

متن را برای استفاده در URL رمزگذاری یا رمزگشایی کنید. با حالت‌های encodeURIComponent و encodeURI.

برنامه‌نویسی
💻

تولید UUID

UUID نسخه ۴ (تصادفی و امن) بسازید. تولید دسته‌ای تا ۱۰۰۰ عدد، حروف بزرگ و بدون خط تیره.

برنامه‌نویسی
💻

تولید هش (Hash)

هش SHA-1، SHA-256، SHA-384 یا SHA-512 متن را با Web Crypto API محاسبه کنید. همه‌چیز محلی و امن.

برنامه‌نویسی
💻

تست Regex

الگوهای Regex را روی متن تست کنید. نمایش هایلایت، لیست تطابق‌ها، گروه‌های نام‌دار، با محافظت از ReDoS.

برنامه‌نویسی
💻

رمزگشای JWT

توکن‌های JWT را رمزگشایی کنید و Header، Payload و وضعیت انقضا را با نمایش خوانا و هشدارهای امنیتی ببینید.

برنامه‌نویسی

🧮 محاسبات

🧮

ماشین حساب درصد

درصد یک عدد، درصد یک مقدار نسبت به کل، و تغییر درصدی بین دو عدد را محاسبه کنید.

محاسبات
🧮

محاسبه سن

سن دقیق خود را بر حسب سال، ماه، روز و همچنین کل روزها، هفته‌ها، ساعت‌ها و دقیقه‌ها محاسبه کنید.

محاسبات
🧮

محاسبه اختلاف تاریخ

اختلاف بین دو تاریخ را بر حسب سال، ماه، روز، هفته، ساعت و دقیقه محاسبه کنید. با محاسبه روزهای کاری.

محاسبات
🧮

مبدل واحد

واحدهای طول، وزن، دما، حجم و مساحت را تبدیل کنید. دقیق و آفلاین.

محاسبات

📈 سئو

📈

تولیدکننده متا تگ

تگ‌های HTML متا، Open Graph و Twitter Card را برای سئو و شبکه‌های اجتماعی تولید کنید.

سئو
📈

پیش‌نمایش نتایج گوگل (SERP)

نحوه نمایش سایت خود را در نتایج جستجوی گوگل مشاهده کنید و طول عنوان و توضیحات را بهینه کنید.

سئو
📈

تولیدکننده robots.txt

فایل robots.txt را برای مدیریت خزنده‌های موتور جستجو (گوگل، بینگ و...) به همراه نقشه سایت (Sitemap) تولید کنید.

سئو
📈

پیش‌نمایش Open Graph

نحوه نمایش لینک سایت خود را در شبکه‌های اجتماعی مانند تلگرام، واتساپ و فیسبوک مشاهده کنید.

سئو

🖼️ تصویر

🖼️

تغییر اندازه تصویر

ابعاد تصویر خود را با حفظ نسبت یا به‌صورت دلخواه تغییر دهید. تمام پردازش‌ها محلی و امن انجام می‌شود.

تصویر
🖼️

فشرده‌سازی تصویر

حجم تصویر خود را بدون افت محسوس کیفیت کاهش دهید. با تنظیم دقیق کیفیت و فرمت خروجی (JPG/WebP).

تصویر
🖼️

تبدیل فرمت تصویر

فرمت تصویر خود را به JPG، PNG یا WebP تبدیل کنید. تمام پردازش‌ها محلی انجام می‌شود.

تصویر
🖼️

انتخاب رنگ از تصویر

روی هر نقطه از تصویر کلیک کنید تا کد رنگ (HEX و RGB) آن را کپی کنید. ابزاری ضروری برای طراحان.

تصویر

🎨 رنگ و طراحی

🎨

تولیدکننده پالت رنگ

از یک رنگ پایه، پالت‌های هارمونیک (مکمل، آنالوگ، سه‌گانه، چهارگانه، تک‌رنگ، Split) بسازید و کد HEX را کپی کنید.

رنگ و طراحی
🎨

تولیدکننده گرادیانت CSS

گرادیانت‌های خطی و شعاعی زیبا بسازید، پیش‌نمایش زنده ببینید و کد CSS آماده را کپی کنید.

رنگ و طراحی
🎨

بررسی کنتراست رنگ (WCAG)

کنتراست بین رنگ متن و پس‌زمینه را بر اساس استانداردهای WCAG AA و AAA بررسی کنید.

رنگ و طراحی
🎨

تولیدکننده سایه جعبه (Box Shadow)

سایه‌های جذاب برای عناصر CSS بسازید، پیش‌نمایش زنده ببینید و کد آماده را کپی کنید.

رنگ و طراحی

📅 تاریخ و زمان

📅

مبدل تاریخ شمسی، میلادی و قمری

تاریخ را بین سه تقویم شمسی (جلالی)، میلادی (گرگوری) و قمری (هجری) به صورت لحظه‌ای تبدیل کنید.

تاریخ و زمان
📅

مبدل تایم‌استمپ یونیکس

تایم‌استمپ یونیکس را به تاریخ (شمسی، میلادی، قمری) و برعکس تبدیل کنید. با نمایش خودکار زمان فعلی.

تاریخ و زمان
📅

ماشین حساب تاریخ

روز، هفته، ماه یا سال به یک تاریخ اضافه یا کم کنید. نتیجه در سه تقویم شمسی، میلادی و قمری نمایش داده می‌شود.

تاریخ و زمان
📅

اطلاعات کامل تاریخ

تمام اطلاعات یک تاریخ: روز هفته، شماره روز سال، شماره هفته، سال کبیسه، روزهای باقیمانده تا پایان سال.

تاریخ و زمان

📁

مشاهده اطلاعات فایل و هش

اطلاعات دقیق فایل (حجم، نوع، پسوند) را ببینید و هش SHA-256 آن را برای بررسی اصالت محاسبه کنید.

فایل
📁

تبدیل فایل به Base64

فایل خود (مانند تصویر، PDF یا فونت) را به متن Base64 تبدیل کنید تا در کدهای HTML یا CSS استفاده کنید.

فایل
📁

مبدل CSV به JSON و برعکس

داده‌های CSV را به JSON یا JSON را به CSV تبدیل کنید.
