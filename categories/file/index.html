مشاهده اطلاعات فایل و هش

مشخصات فایل مانند نام، نوع، پسوند و اندازه را ببینید و هش SHA-256 را برای بررسی یکپارچگی و اصالت فایل در همان مرورگر محاسبه کنید.

تبدیل فایل به Base64

تصویر، PDF، فونت یا هر فایل دیگری را به رشته Base64 تبدیل کنید و خروجی را برای استفاده در HTML، CSS یا برنامه‌نویسی کپی کنید.

مبدل CSV به JSON و برعکس

فایل یا متن CSV را به JSON تبدیل کنید و JSON را دوباره به CSV برگردانید؛ جداکننده، سرستون‌ها و داده‌های چندخطی را کنترل کنید.
